# Módulo 3: Backoffice Admin

Entorno privado de administración (prefijo público `/140210`): acceso con roles ADMIN/OPERATOR, catálogo e inventario, multimedia, finanzas, usuarios y las pantallas de órdenes y reposición.

La documentación completa del módulo (rutas, permisos, contratos de API, datos, despliegue, pruebas y trazabilidad de los tickets ADM-01 a ADM-05) vive en **[docs/modulos/admin](../../../docs/modulos/admin/README.md)**.

Al cambiar este módulo, actualiza la página de la funcionalidad correspondiente y la tabla de trazabilidad de ese README.
